# VOZ-TRADUCTOR (VozBridge)

Código fuente exportado desde Floot. Incluye traductor de viajes, chat con IA, carga de fotos, interfaz InsurTalent y tema claro/oscuro.

**Nota:** los endpoints originales dependen de `@floot/ai` y del runtime de Floot. La exportación conserva esos archivos, pero para ejecutarlo fuera de Floot es necesario adaptar el backend de IA, las rutas y los assets a un servidor propio. No se incluyen claves ni secretos.

Repositorio independiente del proyecto TALENT.
